> **«АГАТ»** — конфигурация на платформе **«1С:Предприятие 8.3»** (разработка в среде **1C:EDT**), объединяющая комплексный электронный документооборот (СЭД), оперативный и складской учет, расчет зарплаты, планирование задач и интеллектуальную аналитику на базе современных больших языковых моделей (LLM).

### 1. 📁 Документооборот (СЭД)
* **Договорная работа:** регистрация и ведение договоров с контрагентами, договоров субподряда, спецификаций и дополнительных соглашений.
* **Распорядительные документы:** учет распоряжений генерального директора (ГД), распоряжений технического директора (ТД), приказов и протоколов.
* **Корреспонденция:** полный цикл регистрации входящих и исходящих писем, контроль адресатов и исполнителей.
* **Локальные нормативные акты и служебные документы:** корпоративное право, учредительные документы, доверенности, документы по недвижимости и проектам.
* **Хранилище файлов:** файлы и сканы документов хранятся в томах на внешнем сервере без раздувания базы данных.

### 2. 📅 Планировщик задач
* Интерактивное планирование задач сотрудников и подразделений.
* Визуальное отображение сроков и этапов на диаграмме Ганта.
* Контроль дедлайнов и статусов исполнения.

### 3. 📦 Оперативный, складской и бухгалтерский учет
* Оформление приходных накладных, учет остатков ТМЦ по складам.
* Списание материалов в производство (`РасходПроизводство`).
* Регистры бухгалтерского учета с поддержкой двойной записи и планов счетов.

### 4. 👥 Кадровый учет и расчет заработной платы
* Ведение справочника сотрудников и видов графиков работы.
* Документы `НачисленияСотрудникам` с расчетом по регистрам расчета (основные начисления, надбавки, удержания).

### 5. 🔄 Распределенная база (РИБ)
* Встроенные планы обмена `Филиалы` и `Отделения` для работы территориально распределенной сети.

## 🤖 Интеграция с искусственным интеллектом (AI Connector)

В конфигурацию интегрирована подсистема работы с языковыми моделями на базе открытого расширения **[ИИкона (1c-ai-connector)](https://github.com/andromanpro/1c-ai-connector)**.

> 📖 **Полная документация по возможностям, настройке провайдеров, агентской петле и API находится в репозитории:**  
> 👉 **[https://github.com/andromanpro/1c-ai-connector](https://github.com/andromanpro/1c-ai-connector)**

### Возможности ИИ в проекте «АГАТ»:

* **Поддержка любых LLM-провайдеров:** OpenAI (GPT-4o), Anthropic (Claude 3.5 Sonnet / Opus), Google Gemini, DeepSeek, YandexGPT, Сбер GigaChat, локальные модели через Ollama.
* **Эксперты ИИ (цифровые ассистенты):** преднастроенные роли с системными промптами:
  * *Аудитор договоров:* проверка рисков, штрафов и расхождений в условиях.
  * *Генератор диаграмм:* построение блок-схем и архитектурных диаграмм по текстовому описанию (Mermaid, PlantUML, BPMN).
  * *Аналитик техподдержки:* экспресс-ответы на вопросы пользователей.
* **RAG (База знаний):** семантический поиск по загруженным регламентам, инструкциям и нормативным документам организации.
* **Мониторинг ошибок:** автоматический сбор критических событий из журнала регистрации с ИИ-диагностикой причин и формированием рекомендаций.
* **MCP-сервер:** поддержка протокола Model Context Protocol (JSON-RPC) для подключения внешних агентов (Claude Desktop, Cursor, Antigravity) к данным базы 1С.

### Пример программного вызова ИИ из модулей 1С:


## 🚀 Быстрый старт и развертывание

### 1. Открытие проекта в 1C:EDT
1. Клонируйте репозиторий проекта в рабочий каталог:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   ```
2. Импортируйте проект `Agat` в рабочее пространство 1C:EDT.
3. Настройте привязку к информационной базе 1С.

### 2. Подключение и настройка расширения ИИ
1. Подключите файл расширения `IIkona_ConnectorAI_v1.3.0.cfe` в информационную базу.
2. В режиме «1С:Предприятие» перейдите в раздел **«Коннектор ИИ» ➔ «Модели ИИ»**.
3. Нажмите кнопку **«Заполнить модели»** для загрузки предустановленных шаблонов провайдеров.
4. Откройте нужную модель (например, OpenAI или DeepSeek), укажите ваш **API-ключ** и сохраните элемент.
5. Проверьте отправку запросов через пункт **«Коннектор ИИ» ➔ «Сервис» ➔ «Тест ИИ»**.

## 🔒 Безопасность и ролевая модель

В конфигурации реализована матрица доступа на основе 12+ ролей:
* `Администратор` — полный доступ к конфигурации и администрированию.
* `Бухгалтер` — доступ к регистрам бухгалтерии, накладным и взаиморасчетам.
* `ГенеральныйДиректор` / `ТехническийДиректор` — доступ к распоряжениям и согласованиям.
* `Кадровик` / `РасчетчикЗарплаты` — учет сотрудников, табелей и начислений.
* `Делопроизводитель` — регистрация входящей/исходящей документации и актов.
* `КИИ_ПолныеПрава` / `КИИ_Пользователь` — права на работу с ИИ-моделями и экспертами.
